# Windows Recon Básico

## Objetivo

Aprender a identificar información básica de Windows utilizando herramientas nativas

## Comandos utilizados 

### whoami

Resultado:
- Usuario: ghia-minipc/admin

### hostname

Resultado:
- Equipo: GHIA-MINIPC

### ipconfig /all

Información obtenida:
- IPv4
- Máscara de subred
- -Gateway
- DNS

### ping google.com

Resultado:
- Conectividad exitosa
- Sin pérdida de paquetes

### netstat -ano

Puertos observados:
- 135
- 445
- 3389

### Procesos identificados

- chrome.exe
- svchost.exe
- msedgewebview2.exe
- StartMenuExperienceHost.exe

### Servicios identificados

- CDPSvc
- TermSerbice

## Aprendizajes

- Identificación de usuarios.
- Identificación de equipos.
- Análisis básico de red.
- Relación entre puertos, procesos y servicios.
- Identificación de conexiones activas.
